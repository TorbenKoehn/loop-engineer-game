Round 1. This task adds `src/run/meta/` with `MetaState`, `newMeta`, `metaView` and `endRun(meta, run, extras?)`, plus the lesson offer and the `pickLesson`/`skipLesson` actions at run end. `RunStats` gains a run-wide `zoneMs`, and `RunResult` gains `lessons`. The raw diff is 643+/42- lines. Production is 272+/11- lines across 9 files, under the 400-line budget. Everything is staged and nothing is untracked. `npm run check` passed with 0 harness errors. `npx vitest run src/run` passed 94 tests in 7 files.

Judgement calls (all acceptable and documented in the Notes and in run-state.md):
- **Run numbering:** `MetaView.run` is optional so the UI stub still compiles. `metaView` numbers runs `lastRun + 1`. Run 0 is never deduplicated, so the "idempotent by run id" guarantee holds for every run built via `metaView`. That is the only path the docs prescribe.
- **endRun extras:** the caller passes `wallMs` and `save`, which default to null. This keeps the core pure, because it has no clock or codec.
- **Lesson offer at run end:** the T048 tests now assert `pending: lessonOffer` and then `[]` after `skipLesson`. The final assertions are not weakened. The property loop runs until no action is legal, which still covers runEnd.
- **stats.cause for wins:** using the last hit taken is a fair reading of "the enemy (or Deadline) that ended the run". It is usually the boss in M1. History records `cause` only for `ctrlc` ("cause of death").
- **Spec fit:** history fields match meta-progression.md "Run history". Lint is stored as rule ids, and sim time as `zoneMs`. Capacity 1 and the `brute_force` unlock match vertical-slice.md. Deadline counts as Process only for source 2, which matches memories-lessons.md.
