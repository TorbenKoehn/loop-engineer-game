A won Release ends it as `shipped`, with no reward. `abandon` is legal on the map only and ends the run as `abandoned` with `pending: null`. The raw diff is 327+/35- lines, of which production is 163 lines across 8 files, under the 400-line budget. Everything is staged and `git status` shows no unstaged or untracked files. `npm run check` passed, with 0 lint errors. `src/run` now has 14 files, which only triggers a warn_at warning.

Spec fit:
