# R073: Review of T037

## Summary

Round 1. This adds Armor layers to `dealDamage` in the order gate -> armor -> Guardrails -> Severity, as combat.md:118 specifies. It also adds a typed `HANDLERS` registry in `src/sim/handlers`: `monolith_stage` is an enemy handler and six ids are passive hooks. The stage switch runs after the intent advance. Two hooks that did nothing before, `rot_no_slow` and `feedback_loop`, now work. Real-content tests live in the new `src/run/boss.test.ts`. `npm run harness:diff` reports production=189 and total=562, within budget. `npm run check` passes (lint: 0 errors, warnings only). Nothing is unstaged or untracked. R064 F1 is closed: all 7 handler ids used by M1 content are registered, and content-model.md describes both handler shapes.
