# R067: Review of T036

## Summary

Round 1. The new `src/sim/combat/enemy/traits.ts` adds four traits. Grow ticks in step 2 before `every` rules. Split runs inside `resolveDead`: children go in at the parent's index, the 5-enemy cap applies, and dropped children are logged as `spawn` with index -1. Outage skips only `applyEffects` in `fire.ts`. Blocked is a gate in `dealDamage` that Deadline `bypass` hits pass through. Step 5 now wins only when the line is empty after resolution. The trait texts match statuses.md "Enemy traits", and the enemies that use them match phase-1-implement.md: Dependency Hell, Scope Creep, Unreachable Service and Yak Shave. Production diff is 178 lines (`npm run harness:diff`; raw total 522). `npm run check` passes (harness lint: 0 errors). Nothing is unstaged. event-log.md and sim-core.md are updated.

- No-spec decisions are sound.

New children start with 0 progress, so they cannot act in step 6 of the same tick.
